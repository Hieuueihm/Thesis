# Thesis ProjectThis is a hardware/software co-design project for FPGA/embedded system.  It includes HDL sources, testbenches, reports, and setup scripts for building and simulating the design.---## 📂 Project Structure```Thesis/├── docs/           # Documentation and specifications├── env.sh          # Environment variable file (generated by setup.sh)├── hdl/            # HDL (Verilog/VHDL/SystemVerilog) source code├── old_version/    # Backup or deprecated versions├── report/         # Reports and result files├── setup.sh        # Script to configure PROJECT_ROOT├── src/            # C/C++ source code (for embedded software if any)└── tb/             # Testbench files for simulation```---## 🚀 How to setupAfter cloning the repository:```git clone https://github.com/yourname/Thesis.gitcd Thesissource setup.shsource env.sh```✅ `setup.sh` will create `env.sh` with `PROJECT_ROOT` pointing to the current project directory.  ✅ `env.sh` will export `PROJECT_ROOT` when sourced.---## ⚙ UsageYou can now use `$PROJECT_ROOT` in your terminal or scripts:```cd $PROJECT_ROOT/hdlcd $PROJECT_ROOT/tb```To use the Python training script:```bashcd $PROJECT_ROOT/src/train/pythonsource auto.sh```
